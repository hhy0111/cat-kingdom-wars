# Cat Kingdom Wars 품질/재방문 설계 보강

## 목표

- 첫 실행, 로딩, 로비, 전투 진입이 하나의 완성된 게임처럼 느껴지게 만든다.
- 다음날 재접속 이유를 전투력 성장, 수집, 이벤트, 시각 보상으로 분산한다.
- 광고와 결제는 진행 차단이 아니라 보상 확대, 시간 단축, 꾸미기, 편의성으로 연결한다.

## 시작 화면

- 성문, 왕국 문장, 행군하는 냥이 부대, 반짝임, 깃발 흔들림을 배치한다.
- 버튼은 `새 왕국 시작`, `이어하기`로 분리한다.
- 첫 화면에서 바로 다음날 보상을 보여준다.
- 추후 이미지 적용 시 배경은 `opening_kingdom_dawn.webp`, 성은 `opening_castle_layer.png`, 전경 행군은 `opening_marching_cats_spritesheet.png`로 분리한다.

## 로딩 화면

- 로딩은 단순 대기 화면이 아니라 전장 준비 연출로 사용한다.
- 표시 요소:
  - 현재 이동 목적지
  - 진행률 바
  - 4직업 냥이 파티 행군 애니메이션
  - 짧은 전략 팁
- 사용처:
  - 시작 화면에서 로비 진입
  - 로비에서 전투 진입
  - 결과 화면에서 재도전
- 추후 실제 에셋 적용 시 `loading_party_spritesheet.png`, `loading_road_layer.png`, `loading_tips_panel.png`로 분리한다.

## 로비 화면

- 로비는 단순 메뉴가 아니라 “오늘 할 일”이 한눈에 보이는 왕국 허브여야 한다.
- 핵심 패널:
  - 오늘의 보상: 7일 접속 트랙
  - 오늘의 임무: 전투 참여, 스킬 사용, 기지 파괴
  - 오늘의 전선: 하루 단위 특수 스테이지
  - 왕국 패스: 반복 플레이 보상 트랙
  - 시간 보상 상자: 방치 보상 회수 지점
- 로비 건물:
  - 왕성: 기지/생산 성장
  - 연구소: 영구 연구
  - 상점: 상품, 광고 보상, 스킨
  - 전투 포털: 다음 추천 스테이지

## 다음날 다시 하고 싶어지는 요소

### 1. 7일 접속 보상

- 1일차: Gold
- 2일차: Fish
- 3일차: 스킬 강화 재료
- 4일차: 슈퍼냥 조각
- 5일차: 전투 아이템
- 6일차: 스킨 조각
- 7일차: 슈퍼냥 소환권
- 보상형 광고 연결: 수령 보상 2배, 단 1일 1회.

### 2. 오늘의 임무

- 하루 3개만 제공해 피로도를 낮춘다.
- 전투 루프를 가볍게 유도한다.
- 예시:
  - 전투 3회 참여
  - 화염 스킬 5회 사용
  - 중립기지 1회 점령
  - 슈퍼냥 1회 소환
- 결제 연결: 월정액은 임무 보상 +20%, 임무 자동 완료는 금지.

### 3. 시간 보상

- 전투하지 않아도 2~8시간 단위로 Gold/Fish를 축적한다.
- 복귀 시 상자 개봉 연출을 강하게 만든다.
- 광고 연결: 시간 보상 2배.
- 결제 연결: 월정액은 최대 누적 시간 증가.

### 4. 오늘의 전선

- 매일 하나의 변형 전장을 제공한다.
- 예시:
  - 생산속도 +30%, 체력 -10%
  - 중앙 중립기지 강화
  - 적 궁수 비중 증가
  - 스킬 쿨타임 증가 대신 보상 증가
- 핵심은 같은 스테이지 반복이 아니라 다른 전투 리듬을 주는 것이다.

### 5. 왕국 패스

- 무료 트랙과 프리미엄 트랙을 분리한다.
- 무료 트랙에서도 성장 재화와 스킨 조각을 준다.
- 프리미엄 트랙은 스킨, 이펙트 색상, 로비 장식, 추가 보상 중심으로 구성한다.
- Pay-to-Win을 줄이기 위해 직접 전투력 상품 비중은 낮춘다.

### 6. 수집 목표

- 슈퍼냥 조각 수집
- 직업별 스킨 수집
- 기지 외형 수집
- 스킬 이펙트 스킨 수집
- 로비 장식 수집
- 수집 보상은 전투력보다 시각적 만족과 작은 편의 보너스 중심으로 설계한다.

## 게임 품질 보강 체크리스트

- 시작 화면에서 3초 안에 게임의 장르와 분위기가 보여야 한다.
- 로딩 화면은 무표정한 대기 화면이 아니라 전장 준비 연출이어야 한다.
- 로비 화면에는 다음 행동이 최소 3개 보여야 한다: 전투, 보상, 성장.
- 전투 진입 버튼은 항상 명확해야 한다.
- 무료 보상과 유료 보상은 화면에서 구분되어야 한다.
- 광고 버튼은 강제 느낌이 아니라 “추가 보상”으로 보여야 한다.
- 매일 접속 보상은 과도하게 복잡하지 않아야 한다.
- 1일 플레이 목표는 5~10분 안에 달성 가능해야 한다.
- 30일 이상 목표는 스킨/슈퍼냥/왕국 장식 수집으로 만든다.
