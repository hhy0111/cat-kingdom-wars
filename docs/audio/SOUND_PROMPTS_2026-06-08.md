# Cat Kingdom Wars Sound Prompt Pack

Purpose: Generate production-ready sound assets for the current mobile portrait web game. Keep every file short, clean, loopable where noted, and easy to mix under Korean UI text. Avoid vocals, spoken words, copyrighted melodies, harsh clipping, and long cinematic tails.

## Global Audio Direction

- Style: cute fantasy kingdom war, bright mobile game, warm orchestral colors, light percussion, playful cat kingdom identity.
- Mix target: mobile speakers first, clear midrange, no sub-bass dependency.
- Loudness: consistent game-ready volume, leave headroom, no limiter distortion.
- Format target: WAV source, export-ready OGG/MP3 later.
- Naming convention: `bgm_lobby_loop`, `sfx_unit_cat_melee_01`, etc.

## Background Music

### bgm_opening_loop
Prompt:
Create a 30-second seamless loop for a cute fantasy mobile game title screen. Warm castle morning mood, soft bells, light strings, gentle harp glissando, tiny magical sparkles, hopeful and premium. No vocals, no lyrics, no recognizable melody. Must loop smoothly without an obvious ending.

### bgm_battle_loop

Create a 60-second seamless loop for a cute tactical lane battle. Energetic but not stressful, marching snare, light brass stabs, strings rhythm, playful heroic fantasy. Keep percussion clear on mobile speakers. No vocals, no dark horror tone. Seamless loop.

### bgm_victory_stinger
Prompt:
Create a 5-second victory fanfare for a cute fantasy cat kingdom battle. Bright brass, bells, happy drum hit, sparkling finish. Must feel rewarding and premium, not too loud or comedic.

### bgm_defeat_stinger
Prompt:
Create a 4-second soft defeat stinger for a cute mobile strategy game. Muted strings, small descending bell phrase, gentle sigh-like cadence. Avoid depressing or scary mood; it should imply "try again".
